# AngieSun Portfolio

High-fidelity local rebuild of Angie Sun's Wix Studio portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included routes

- `/`
- `/work`
- `/aboutme`
- `/waterfall`
- `/emard`
- `/bsc`
- `/boulder`
- `/sfhs`
- `/fillin`
- `/catian`
- `/materials-and-manufacture`
- `/privacy-policy`
- `/accessibility-statement`

## WeChat QR code

The footer currently contains an explicit QR-code placeholder because the real WeChat QR image has not been supplied. Add the final image under `public/assets/` and replace the placeholder block in `components/Footer.tsx` with an image element.

## Build

```bash
npm run build
```
